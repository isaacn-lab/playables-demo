# Google Playables demos
 
Demo games built in the Google playable ad format. Each game is a single self-contained `index.html` with no build step and no external requests.
 
## Games
 
| Folder | Game | What you do |
| --- | --- | --- |
| `sand-art/` | Sand Art: Mountain | Pour coloured sand from a funnel to paint a mountain sunset. Accuracy against the target picture is scored live. |
| `featherlight/` | Featherlight: Set up fans, press Simulate, and let the wind carry a feather to its nest. |
 
## Running a game
 
Open the game's `index.html` in a browser, or use GitHub Pages:
 
```
https://<username>.github.io/<repo>/<folder>/
```
